# C++ Personal Finance Tracker

A command-line personal finance application built with C++ to track income, expenses, balances, and spending by category. The application stores transaction data locally so records remain available between sessions.

## Features

- Add income and expenses
- Categorize transactions
- View current account balance
- Display transaction history
- Generate financial summaries
- Analyze expenses by category
- Save transactions to a local file
- Validate user input

## Technologies

- C++
- STL (Vectors)
- Structs
- File I/O (`ifstream`, `ofstream`)
- Input validation
- Git & GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abdulansar417/cpp-personal-finance-tracker.git
cd cpp-personal-finance-tracker
```

### 2. Compile

```bash
g++ -std=c++17 main.cpp -o finance_tracker
```

### 3. Run

```bash
./finance_tracker
```
